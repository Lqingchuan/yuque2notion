# 我把 2000 篇语雀笔记搬进了 Notion，发现官方工具全都不好使

> 全程由 AI 智能体完成，我把完整的踩坑经验和脚本开源了——你也可以直接把提示词喂给 AI 复刻一遍。

## 起因

用语雀五六年，攒了 50 个知识库、2000 多篇文档：日记、逆向笔记、CSDN/掘金剪藏、有道迁移过来的旧笔记、还有大量 iPhone 直传的照片。想整体搬去 Notion，第一反应是找现成工具——结果全踩坑：

- **语雀官方导出**：要逐库手动操作，而且很多账号连整库导出权限都被收回了；
- **开源下载器（yuque-dl 之类）**：下载回来的东西一半是空的；
- **Notion 官方导入**：根本不认语雀格式。

后来排查才发现一个惊人的事实：**语雀的 `/markdown` 导出端点，对我账号里 70% 的文档返回的是"导入数据处理"占位空页**——HTTP 200、请求成功，但正文是空的。所有走这个端点的开源工具，拿到的东西天然就是残缺的。这不是工具的锅，是端点本身对存量文档失效了。

## 解法：绕开导出端点，直接读详情接口

在语雀网页的登录会话里试了一下文档详情接口：

```
GET /api/docs/{slug}?book_id={bookId}&format=lake
```

返回的 `content` 字段是完整的 lake 格式正文——之前 markdown 端点丢掉的内容全都在，连 2021 年老文档里的图片卡片都完好无损。

于是整条管线变成了：

```
浏览器登录会话抓取 → lake 转 Markdown → 图片下载转存 → Notion API 导入 → 图片二次修复
```

5 个环节，7 个脚本，全部开源（文末）。

## 踩坑合集（都是真金白银的时间换来的）

**1. lake 格式是个私货。** 图片、附件、公式在 lake 里都是 `<card name="image" value="data:URL编码的JSON">` 这种套娃语法，得自己解码还原成 Markdown。转完还得把 turndown 的转义还原（`!\[` → `![`），不然图片语法直接失效。

**2. 语雀的图片分两种，命运完全不同。** `cdn.nlark.com` 的图是公开 CDN，直接下载就行；但网页剪藏的图几乎全是 `yuque.com/attachments/...`——**需要登录态才能访问**，curl 下去直接 302 到登录页。解法是在登录会话里 fetch 一遍，拿到 302 后的签名直链，趁几小时有效期赶紧下载。更阴的是这批图全部以 `octet-stream` 存储，扩展名完全不可信，得靠文件魔数识别真实格式。

**3. iPhone 照片是 HEIC，Notion 不认。** 一行 `sips -s format jpeg` 解决，macOS 自带。

**4. Notion API 的校验比想象中矫情。** Markdown 里的自动链接会产生 `http://www.xxx.com]WiFi` 这种 URL（带 `]`）、或者带中文乱码的链接，Notion 直接 400 拒收整批内容。必须先做严格校验：ASCII 可打印字符 + `new URL()` 能解析，不过关就删链接保文字。还有：引用块不许嵌套子块、单条富文本 2000 字符上限、标题截断切断 emoji 的代理对会导致 "Error parsing JSON body"……

**5. 图片"变成链接"是最后一坑。** 前面全做对了，打开 Notion 还是发现很多图片显示为一条链接。原因：正文里**行内**的图片（跟文字混在一行的）会被 Markdown 解析降级成纯文本 URL 或链接，而不是图片块。需要一个收尾脚本：扫描全部页面，把纯 URL 文本段删掉、原位插入真正的图片块。

**6. 慢，但有下限。** Notion API 全局限速 3 请求/秒，2000 篇文档 + 6400 张图的导入是两万多次 API 调用，物理下限就是几个小时。断点续传必须有，中断了随时重跑。

## 结果

36 个知识库、2053 个页面（含分组目录）、约 4900 个图片块，层级和目录顺序完整还原，图片全部转成 Notion 托管文件（不再依赖语雀的登录态，以后语雀挂了图也在）。每篇底部自动附上语雀原文链接和日期，方便回溯。

## 你也可以直接"喂给 AI"

这次整个迁移是 AI 智能体（ZCode）端到端完成的：账号分析、方案论证、抓取、转换、修 bug、验收，我只做了三件事——在浏览器里登录、点了一次令牌创建按钮、把令牌粘贴给它。

所以我把整条管线沉淀成了一份**提示词**：包含流程编排和上面所有踩坑细节（占位端点、签名直链、octet-stream、Notion 校验规则……），配套 7 个按序编号的脚本。

用法二选一：

- **手动流**：按 README 的 5 条命令自己跑，Console 脚本复制粘贴即可，不需要把密码交给任何人；
- **AI 流**：把 `PROMPT-FOR-AI.md` + 脚本包发给 AI 编程助手（Claude Code / Cursor / ZCode 都行），它会带着你走完全程——你要做的只是在浏览器里登录语雀、提供 Notion 令牌。
